## Required fields for a new entry

1. Unique ID and UTC start time.
2. Exact Git revisions, model revisions, images, and host roles.
3. One hypothesis and one intentional variable change.
4. Expected observation and stop condition.
5. Command or script name; secrets omitted.
6. Result: PASS, FAIL, BLOCKED, or INCONCLUSIVE.
7. Raw-log location and SHA-256 hashes.
8. Failure cause only when proven; otherwise label it unknown.
9. Lesson and the next smallest discriminating test.

Use `scripts/run-experiment.sh ID "short label" command ...` to preserve the
raw output, exit code, UTC times, and SHA-256 hash. Then append the result here.
